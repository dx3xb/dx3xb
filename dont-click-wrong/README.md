# 不要点错 / Don't Tap Wrong

dx3xb 感官与脑力三件套中的反应控制挑战。玩家需要在 60 秒内根据颜色与形状指令选择正确图形；点对加分，点错扣时。

## 本地开发

```bash
npm install
npm run dev
npm run build
```

## 产品约定

- 正式地址：`https://dont-click-wrong.dx3xb.com`
- 分享链接携带 `seed`，保证好友挑战同一套题。
- 图形选项必须保持原生按钮语义和键盘可操作性。
- 百分位是娱乐性估算，不能表述为真实玩家分布或能力诊断。
- 结果文案可以轻调侃，但不得使用疾病、残障或年龄群体作为负面称号。

主站通过 `dx3xb_toys` 目录读取此项目的上线状态；项目作为独立 Vercel 应用部署。
